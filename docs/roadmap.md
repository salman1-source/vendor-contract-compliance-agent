# خارطة الطريق

كل وظيفة بعد Phase 1 مخططة، ولا تعني هذه الخارطة أنها منفذة.

## Phase 1: Foundation

**الأعمال المطلوبة:** تثبيت الغرض وحدود الصلاحية، توثيق المعمارية والأمان، إنشاء مصفوفة التقييم، تحديد مراحل التسليم، وتجهيز سياسة حفظ الأدلة والإعدادات الآمنة.

**شرط الخروج:** مراجعة الوثائق وروابطها ومخطط Mermaid، اجتياز فحص الأسرار، وإثبات أن المستودع لا يحتوي وظيفة AI تشغيلية أو تبعيات خارج نطاق المرحلة.

## Phase 2: Deterministic vertical slice — Completed

**الحالة المثبتة:** اجتاز المسار الحتمي المصطنع اختبارات الوحدة والتكامل وCLI، وحُفظت تقارير التشغيل ونتائج الاختبار في `evidence/phase2`. لا يتضمن ذلك وكيلًا أو ذكاءً اصطناعيًا أو رأيًا قانونيًا.

**الأعمال المطلوبة:** إنشاء بيانات PDF وسياسات مصطنعة، وبناء مسار حتمي صغير للفحص والاستخراج والمقارنة والتقرير باستخدام مخرجات Typed، مع اختبارات وحدات وتكامل.

**شرط الخروج:** اختبار end-to-end منفذ وقابل لإعادة الإنتاج على fixture مصطنع، مع تقرير مرتبط بالأدلة ومسار فشل مضبوط؛ دون ادعاء قدرات وكيلة غير موجودة.

## Phase 3: Agentic workflow — Planned

**الأعمال المطلوبة:** تطبيق LangGraph StateGraph وPlan-and-Execute والأدوار الأربعة واستدعاءات الأدوات الحقيقية والتوجيه الشرطي وإعادة المحاولة المحدودة.

**شرط الخروج:** Traces واختبارات منفذة تثبت المسار الناجح، والمراجعة المستقلة، ومسار bounded retry الذي يتوقف عند الحد.

## Phase 4: Security and observability

**الأعمال المطلوبة:** تطبيق فحص المدخلات، وكشف Prompt Injection، وTyped validation، وredaction، وfail closed، وإضافة tracing وmetrics واختبارات عدائية.

**شرط الخروج:** أدلة منفذة على حظر عينة الحقن، وحجب البيانات الحساسة، والفشل المضبوط، مع Trace وmetrics غير حساسة لكل مسار.

## Phase 5: Persistence, human approval, and delivery

**الأعمال المطلوبة:** إضافة SQLite checkpoints وinterrupt/resume بشري حقيقي، ثم FastAPI وDocker Compose وفحوص الصحة ووثائق التشغيل.

**شرط الخروج:** اختبار محفوظ يثبت التوقف وإعادة التشغيل واستعادة الحالة، وتوقف النتيجة الحرجة حتى القرار البشري ثم استكمالها، ونجاح health check للـ API عبر Docker Compose.
